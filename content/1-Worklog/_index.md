This section summarizes the daily engineering worklog across the 12-week internship program of **First Cloud AI Journey (FCAJ) — AWS Vietnam** (from **August 17, 2026** to **November 06, 2026**).

The core focus of the internship was researching AWS Serverless, NoSQL, and Generative AI services to architect and implement **EduMedia AI** — a smart lecture storage and search engine on AWS.

---

### 12-Week Summary:

* **[Week 1: Onboarding & FCAJ Guidelines](1.1-week1/)** — Completed Portal onboarding, local dev toolchain configuration, and project Git repository setup.
* **[Week 2: Amazon S3 & IAM Access Security](1.2-week2/)** — Configured S3 Media Bucket and enforced IAM Least Privilege permissions for Lambda.
* **[Week 3: Serverless Architecture with AWS Lambda](1.3-week3/)** — Evaluated Lambda event-driven execution triggered by S3 ObjectCreated events.
* **[Week 4: Amazon Rekognition & Transcribe Exploration](1.4-week4/)** — Tested image label detection and Vietnamese speech-to-text APIs.
* **[Week 5: AgentSys Architecture & Proposal Writing](1.5-week5/)** — Designed 6-service system architecture diagram and completed workshop proposal.
* **[Week 6: S3 Ingestion Infrastructure Setup](1.6-week6/)** — Configured S3 Event Notifications and deployed ingestion Lambda handlers.
* **[Week 7: Rekognition & Transcribe Integration](1.7-week7/)** — Built automated metadata extraction pipelines across JPG, PNG, MP3, and MP4 media assets.
* **[Week 8: Metadata Store on Amazon DynamoDB](1.8-week8/)** — Designed NoSQL schemas and provisioned AgentSysMediaMetadata DynamoDB table.
* **[Week 9: Amazon Bedrock (Nova Lite & Titan Embeddings V2)](1.9-week9/)** — Integrated Bedrock API for intelligent query planning and semantic vector search.
* **[Week 10: Web UI Engineering & Client Integration](1.10-week10/)** — Developed React/Vite Web Gallery, Click-to-Seek Media Player, and input validation guardrails.
* **[Week 11: Automated Testing Suite & Technical Blog Authoring](1.11-week11/)** — Built 143-test Pytest suite with Moto mocks, configured 7 CloudWatch Alarms, authored 2 personal technical blogs, and coordinated community publishing.
* **[Week 12: Workshop Documentation & Project Finalization](1.12-week12/)** — Authored complete 7-part workshop guide, validated automated cleanup runbook, and completed project verification.
